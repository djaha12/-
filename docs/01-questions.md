# ATELIER — Фаза 0: вопросы к Dars

К каждому вопросу — моя рекомендация-дефолт. Ответ «всё по дефолту» разблокирует работу целиком;
можно ответить точечно номерами («1 — да, 5 — вариант Б…»).

**1. Хостинг и бюджет.**
Дефолт: Hetzner VPS (Docker Compose: web, services, Postgres, Redis, Meilisearch) + Cloudflare CDN +
Cloudflare R2 для изображений + staging-стенд + бэкапы в R2. ~$50–80/мес, полный контроль, дёшево для региона.
Альтернатива: Vercel + Neon + Upstash (быстрее старт, дороже на росте, WS-сервису всё равно нужен отдельный хост).
Есть ли предпочтения/бюджет?

**2. Канал OTP.**
Дефолт: Telegram Gateway как первичный (дёшево, регион в Telegram) + SMS-fallback (местный агрегатор,
напр. Nikita Mobile — нужен договор). Или SMS первичный? Есть ли уже договор с SMS-агрегатором?

**3. Instagram-импорт — фазируем?**
Дефолт: MVP — идеальная ручная мобильная загрузка + «вставь ссылки» как помощник структуры;
OAuth-импорт через Graph API (business/creator) — фаза 1.5. Полный автоимпорт технически ненадёжен
(API закрыты/ограничены). Ок?

**4. Модерация trust-tiers вместо тотальной премодерации?**
Дефолт: новые аккаунты — премодерация первых 2–3 кейсов + автопроверки; проверенные — публикация мгновенно,
пост-модерация. Иначе «кейс за 5 минут с телефона» не работает. Ок?

**5. Холодный старт отзывов.** Варианты:
- А (дефолт): строго только верифицированные отзывы; пустоту компенсируем консьерж-онбордингом
  и бейджами верификации — честность как позиционирование.
- Б: разрешить импорт внешних отзывов с жирной меткой «не подтверждён платформой», в рейтинге не участвуют.
Что выбираем?

**6. Агентства в MVP.**
Дефолт: модель организаций в БД с первого дня; в UI — только метка «работает в X» и страница-заглушка агентства.
Полноценные B2B-витрины — после MVP (это и так в монетизации последним пунктом). Ок?

**7. Политика контактов.**
Телефоны скрыты до заявки — ясно. А контакты в текстах кейсов/постов: автоскрытие в публичном контенте
(дефолт) или жёсткая блокировка везде включая чат? Жёсткость злит специалистов, мягкость сливает трафик.
Дефолт: автоскрытие в публичном, в чате свободно.

**8. PRO-платежи на старте.**
Дефолт: система тарифов/лимитов работает с первого дня, активация PRO — админом вручную/промокодами;
Mbank / O!Деньги подключаем как только будут юрлицо и мерчант-договоры (это недели, вне кода).
Есть ли уже юрлицо/договоры?

**9. Сроки и темп.**
Есть ли целевая дата пилота в Бишкеке? Это влияет на то, что режем в M5–M7 (челленджи, посты — первые кандидаты).

**10. Языки контента.**
UI-копирайт пишу на русском как источнике; ky/en — мой перевод с пометкой «нужно ревью носителем» в i18n-файлах.
Есть ли носитель кыргызского для ревью перед запуском?

**11. Название/домен.**
ATELIER — рабочее. Для OG/SEO/Telegram-бота домен понадобится к M6–M7. Есть ли кандидаты?
