# ATELIER — продуктовая спецификация (выжимка ТЗ, источник истины для агентов)

Визуальная платформа для креативных специалистов недвижимости. Рынок: Кыргызстан (Бишкек → Ош → регионы),
далее Казахстан, Узбекистан. Формула: портфолио → репутация → клиенты → рост. Приоритет №1 — UX/UI:
конфликт «удобство vs скорость разработки» всегда решается в пользу удобства.

## Роли
- **Специалист**: риелторы/агентства (ПЕРВАЯ вертикаль — решение 03/§13, детали docs/05),
  архитекторы/бюро, дизайнеры интерьера, ландшафтные дизайнеры, декораторы/хоумстейджеры,
  3D-визуализаторы, фотографы/видеографы недвижимости (вторая волна). НЕ мастера-ремонтники.
- **Клиент**: покупает/строит/ремонтирует. Профиль минимальный (имя, аватар, город, коллекции,
  «N завершённых заказов»).
- **Агентство**: организация со специалистами (MVP: модель в БД + метка «работает в X»).
- **Админ/модератор**.

## Core-функции MVP
### Профиль специалиста (витрина уровня Behance)
Обложка, специализация, стили, город/район, вилка цен (сомы + USD по курсу НБКР), статус «принимаю заказы»,
бейджи верификации (личность, юрлицо/патент), статистика владельцу (просмотры, сохранения, конверсия в заявки).
Телефон скрыт до заявки.

### Кейсы — главная единица контента
Серия фото/рендеров, «до/после»-пары, площадь, бюджет вилкой, сроки, роль автора, команда проекта (теги коллег —
совместные кейсы, рейтинг растёт у всех), метки на фото с комментариями. Черновики + автосохранение.
Мастер создания mobile-first («кейс с телефона за 5 минут»). Чекбокс прав на публикацию фото.
Лимит Free — 5 кейсов.

**Кейс-сделка (риелторы)**: история завершённой сделки, НЕ объявление — тип сделки
(продажа/аренда/подбор), тип объекта, район (без адреса), цена (EXACT/RANGE/HIDDEN), «продано за
N дней», команда предпродажки (стейджер/фотограф), бейдж «Подтверждено клиентом» только через
завершённый заказ. Прошедшее время в микрокопии. Анти-скоуп: не листинг-портал — без объявлений,
статусов «в продаже», карт объектов и ипотечных механик.

### Репутация — честный рейтинг
Отзыв ТОЛЬКО по завершённому заказу внутри платформы. Подшкалы: качество, сроки, коммуникация, бюджет +
текст + фото результата. Публичная история: завершённые проекты, % повторных клиентов.
Антифрод: взаимные подтверждения заказа двумя верифицированными телефонами, чек-поинты с фото повышают
вес отзыва, velocity-лимиты, аномалии → модерация. Импорта внешних отзывов НЕТ (решение 03/5).

### Лента вдохновения
Masonry, бесконечный скролл, фильтры: тип специалиста, стиль, бюджет, город. Коллекции-мудборды клиентов
(анимация сохранения — «момент радости»). Каждое фото → кейс → автор → заявка (лента = воронка).
Гость видит ленту БЕЗ регистрации; регистрация в момент ценности (сохранение, заявка).

### Брифы и заявки
Бриф: задача, тип объекта, площадь, бюджет, сроки, референсы из коллекций. Отклики специалистов
(лимит Free), сравнение профилей рядом, прямая заявка в 2 клика, встроенный чат (текст, фото, файлы, PDF).

### Заказ
Статусы: обсуждение → договорённость → в работе → сдан → завершён (+ отменён, спор). «Сдан» предлагает
специалист, подтверждает клиент (авто-подтверждение через N дней с уведомлением). Чек-поинты с фотофиксацией.
ЗАПРЕЩЕНО: любые кредитные и процентные механики — никогда.

### Рост специалиста
Подписки, лайки, сохранения; публикации-посты; «Проект недели» по честным метрикам; челленджи с голосованием;
платный буст (нативно, с пометкой «продвижение»).

## Монетизация
Free (профиль, 5 кейсов, лимит откликов) → PRO (безлимит, аналитика, приоритет, портфолио-витрина) →
буст → B2B-витрины агентств. Платёжки КР за абстракцией: Mbank, O!Деньги, Элсом, Balance.kg (+ Kaspi Pay
в будущем). На старте PRO активируется вручную/промокодами.

## Обязательные сквозные требования
- Telegram-бот — основной канал уведомлений (deep-link привязка) + push PWA + центр уведомлений in-app.
- Виральность: OG-карточки кейсов/профилей (WhatsApp/Telegram), визитка кейса для сторис.
- SEO: SSR, schema.org (Person/LocalBusiness/Review), sitemap, hreflang; канонические страницы на русском.
- Модерация: trust-tiers (новичок — премодерация первых 3 кейсов), pHash-дубликаты, жалобы, арбитраж споров.
- Защита: телефоны скрыты до заявки, автоскрытие контактов в публичном контенте (в чате свободно),
  rate limiting, EXIF/GPS-стриппинг фото.
- Аналитика: событийная схема с первого дня, дашборд владельца (DAU/WAU, воронка клиент→заявка→заказ→отзыв,
  retention), feature flags (PostHog).
- i18n: ru/ky/en с первого дня, расширяемо на kk/uz. Валюта: сом + отображение USD.
- Доступность WCAG AA; LCP < 2.5s на 3G; CLS ≈ 0; skeleton-загрузка везде.
- Первый запуск: красивая лента без регистрации; онбординг специалиста ≤ 10 минут.

## Визуальный язык
Контент — король, интерфейс почти невидим. Тёплый белый / глубокий графит (dark mode с первого дня),
ОДИН сдержанный акцент (терракота). Manrope (UI) + Lora (display serif, кириллица). Motion 150–250ms,
естественный easing, сдержанно. Состояния пустоты продают действие. Ошибки человеческим языком.
Тач-таргеты 44px+, ключевые действия в зоне большого пальца.
