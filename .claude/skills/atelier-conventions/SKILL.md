# Конвенции ATELIER

## Дизайн-токены (источник: apps/web/src/app/globals.css)
- Фон: тёплая бумага `background` / глубокий графит в dark. Поверхности: `surface`, `surface-muted`.
- ОДИН акцент — терракота (`accent`, `accent-soft`). Семантические (`success`/`danger`/`warning`) — редко и приглушённо.
- Шрифты: `font-sans` = Manrope Variable (UI), `font-display` = Lora Variable (заголовки, крупные цифры).
- Spacing строго 4px-сетка (tailwind-шкала). Радиусы: `rounded-xl` для карточек/фото, `rounded-full` для контролов.
- Motion: 150–250ms, `ease-(--ease-soft)`. Анимации: `animate-fade-up`, `animate-save-pop`. Никакого «цирка».
- Тени: `shadow-card`, `shadow-float` — тёплые, едва заметные. Elevation через тень+бордер, не через тёмные оверлеи.

## Правила UI
- Контент — король: фото занимают максимум, хром интерфейса минимален и нейтрален.
- Один primary-CTA на экран. Терракотовая кнопка — только главное действие.
- Тач-таргеты ≥ 44px (`h-11`/`size-11`). Ключевые действия мобильной версии — в зоне большого пальца (нижний бар).
- Каждый экран обязан иметь: пустое состояние (продаёт действие), ошибку (человеческим языком + путь решения), loading (skeleton, не спиннер на весь экран).
- Изображения: только next/image с width/height и blurDataURL (CLS ≈ 0). Мок-изображения — через `img()` из `@/mock/data`.
- Тексты: русский, обращение на «вы», без канцелярита. Цены: сомы + `≈ $` (formatBudgetRange).
- Dark mode проектируется, не инвертируется: проверяй оба режима перед показом.

## Конвенции кода
- TS strict, никаких `any` без комментария-причины. Компоненты — function declarations, пропсы интерфейсом.
- Server Components по умолчанию; `'use client'` только там, где есть состояние/события.
- Бизнес-инварианты — ТОЛЬКО в `packages/core` (чистые функции + vitest). UI и API их импортируют.
- Никаких кредитных/процентных механик — никогда, даже в мокапах.

## Обязательный цикл для каждого экрана
1. Сверстал → `pnpm gen:mock && pnpm build && pnpm shots`
2. Субагент design-reviewer читает скриншоты (1440/390 × light/dark) → правки
3. Минимум 2–3 цикла, затем показ Dars со скриншотами.

## Чек-лист перед показом блока
- [ ] design-reviewer: «экран готов» или только minor
- [ ] code-reviewer: без blocker/major
- [ ] `pnpm typecheck && pnpm lint && pnpm test` зелёные
- [ ] Скриншоты приложены (обе ширины, обе темы)
- [ ] CLAUDE.md обновлён (статус блока)
